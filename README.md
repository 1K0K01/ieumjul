# 이음줄 (Ieumjul)

PDF에서 긁어온 글의 어색한 줄바꿈을 문단으로 되돌려주는 정적 웹 도구입니다.
"줄을 잇다"에서 이름을 따왔어요. 빌드 과정 없이 `index.html` 하나로 동작하며, 모든 처리는 브라우저 안에서만 이뤄집니다 (파일 업로드 없음).

## 뭘 해주나요

PDF를 드래그해서 텍스트를 복사하면 한 줄마다 줄바꿈이 박히고, 페이지 번호나 머리말·꼬리말까지 같이 딸려옵니다.
이음줄은 pdf.js로 각 글자의 좌표·크기를 읽어서:

- 페이지마다 반복되는 머리말/꼬리말/쪽번호를 찾아 지우고 (`44 · 제목` 같은 조합도 인식)
- 문장이 끝나지 않은 줄은 다음 줄과 이어 붙이고
- 잘린 영어 단어(`exam-` + `ple`)를 다시 붙이고
- 큰 글씨는 마크다운 제목(`#`)으로, 작은 글씨(각주 등)는 선택적으로 제거하고
- `Annot`, `[명사]` 같은 표·2단 라벨 칸은 본문과 뒤섞이지 않게 `[라벨] 내용` 형태로 정리합니다

정리 규칙은 토글로 즉시 켜고 끌 수 있고, PDF를 다시 읽지 않고 바로 재처리됩니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소를 만듭니다 (예: `ieumjul`).
2. 이 폴더의 `index.html`을 저장소 루트에 올리고 커밋합니다.
   - 웹에서: 저장소 페이지 → **Add file → Upload files** → `index.html` 드래그 후 Commit
   - 로컬에서: `git add index.html && git commit -m "add ieumjul" && git push`
3. 저장소 **Settings → Pages**로 이동합니다.
4. **Source**를 `Deploy from a branch`로, 브랜치는 `main` (또는 기본 브랜치), 폴더는 `/ (root)`로 설정하고 저장합니다.
5. 1~2분 뒤 `https://<사용자명>.github.io/ieumjul/` 주소로 접속하면 바로 사용할 수 있습니다.

## 참고

- PDF 파싱은 CDN의 [pdf.js](https://mozilla.github.io/pdf.js/)를 사용합니다. 오프라인 환경에서는 동작하지 않습니다.
- 한글 폰트는 [Pretendard](https://github.com/orioncactus/pretendard), 코드/좌표 표기에는 JetBrains Mono를 CDN으로 불러옵니다.
- 문단 판별, 머리말/꼬리말 감지, 표 라벨 분리는 전부 좌표·글자크기 기반 휴리스틱이라 문서에 따라 완벽하지 않을 수 있습니다. "다듬는 방식" 토글로 조정하세요.
